# Security Knowledge

Store reusable defensive knowledge about authentication, authorization, secure defaults, input handling, secrets, dependency security, vulnerability remediation, testing, isolation, and abuse resistance.

Prioritize root cause, prevention, safe detection, remediation, and regression testing. A proof-of-concept exploit is research material, not an instruction to execute it.

Security claims require evidence and provenance. Important or high-impact lessons should be corroborated before promotion into a skill.
