# Muse Evolution Workspace

`evolution/` records evidence-backed proposals and decisions for improving Muse.

Learning artifacts may inform specialist skills, but protected core rules remain governed separately. Muse may create evaluations and proposals autonomously; changes to `IDENTITY.md`, root `AGENTS.md`, or material security/privacy/data-integrity/production-safety boundaries require human approval before adoption.

Use these states consistently:

- `OBSERVED`
- `SUPPORTED`
- `CANDIDATE`
- `VALIDATED`
- `APPROVED`
- `ADOPTED`
- `REJECTED`
- `STALE`

Never label a proposal `VALIDATED` without actual validation evidence.
