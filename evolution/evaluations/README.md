# Evolution Evaluations

Store evidence and validation results for proposed Muse changes.

Each evaluation should record:

- Proposal reference and current state
- Scenario or behavior being evaluated
- Baseline behavior when available
- Candidate behavior
- Validation method and actual result
- Limitations
- Recommendation: adopt, revise, reject, or revalidate later

Do not treat static inspection as equivalent to real Muse behavior validation. If runtime testing was unavailable, say so explicitly.
